# TaskFlow

Aplicación web para la gestión y organización de tareas.

## Descripción

TaskFlow es una aplicación web desarrollada para facilitar la administración
de tareas mediante una interfaz sencilla, adaptable y fácil de utilizar.

La aplicación permite:

- Crear tareas.
- Asignar prioridades.
- Marcar tareas como completadas.
- Reabrir tareas completadas.
- Eliminar tareas con confirmación.
- Filtrar tareas por estado.
- Consultar el total de tareas.
- Consultar tareas pendientes y completadas.
- Mostrar la fecha de creación de las tareas.
- Conservar las tareas mediante almacenamiento local del navegador.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub
- Apache HTTP Server

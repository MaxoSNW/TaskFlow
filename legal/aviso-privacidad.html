TaskFlow — Aviso de privacidad

Aviso de privacidad

Última actualización: 8 de octubre de 2026.

Este aviso describe el tratamiento de la información en TaskFlow, una aplicación web desarrollada con fines académicos para organizar tareas. La versión descrita se ejecuta en un entorno local de demostración y no representa por sí misma un servicio comercial.

1. Responsable del tratamiento

El responsable del tratamiento de la información es la persona desarrolladora u operadora de esta instancia de demostración de TaskFlow. Antes de utilizar esta plantilla en un servicio público o real, deberá sustituirse esta referencia por el nombre o denominación del responsable y sus datos de contacto efectivos.

2. Información que se almacena

La aplicación almacena la información que el usuario introduce para administrar sus tareas, incluidos el título de cada tarea, su prioridad, su estado de cumplimiento y la fecha de creación registrada por el sistema. Estos datos se almacenan en la base de datos MySQL configurada para la instancia local.

Los títulos de las tareas pueden contener datos personales si el usuario decide escribirlos. Por ello, se recomienda no introducir contraseñas, datos financieros, información sensible ni datos personales de terceros.

3. Finalidades

La información se utiliza para crear, mostrar, organizar, actualizar, completar, reabrir y eliminar tareas, así como para mostrar resúmenes y filtros de actividad. También puede utilizarse para verificar el funcionamiento técnico de esta versión académica.

4. Almacenamiento y comunicación de datos

En la configuración descrita, las tareas se guardan en una base de datos MySQL local accesible a través del servidor de la aplicación. No se ha previsto una función de envío de tareas a terceros ni de publicidad. La configuración de alojamiento, registros técnicos, respaldos o accesos administrativos puede implicar tratamientos adicionales que deben documentarse si la aplicación se publica o cambia de entorno.

5. Conservación y eliminación

Las tareas permanecen almacenadas hasta que se eliminan mediante las funciones disponibles o se borran de la base de datos por la persona administradora. La eliminación desde la interfaz no garantiza la eliminación de copias de seguridad que pudieran existir.

6. Seguridad

La instancia incorpora una conexión HTTPS local y encabezados de seguridad configurados en el entorno de desarrollo. Estas medidas reducen ciertos riesgos, pero no garantizan seguridad absoluta. El usuario debe evitar ingresar información confidencial en esta demostración.

7. Derechos y solicitudes

Para solicitar información, corrección o eliminación de datos asociados a una tarea, debe contactarse a la persona responsable de esta instancia. Si TaskFlow se utiliza como un servicio real en México, el responsable deberá identificar un medio de contacto efectivo y atender los derechos que resulten aplicables conforme a la legislación vigente.

8. Cambios al aviso

Este aviso puede actualizarse cuando cambien las funciones, la infraestructura o las prácticas de tratamiento de información. La fecha de actualización se modificará al publicar una nueva versión.

9. Alcance académico

Este documento es una plantilla informativa para una demostración académica. No sustituye una revisión jurídica ni acredita por sí solo el cumplimiento de las obligaciones legales aplicables a un responsable concreto.

Recomendación: utiliza únicamente tareas ficticias durante las pruebas de la aplicación.
